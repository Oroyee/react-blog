Supervised runs

A charter in. A finished run out.

  1. Charter

    One goal, a few limits, and the checkpoints where you decide.

  2. Team lead plans

    A headless Claude Code, a Chiliz session, or an external window.

  3. Agents build

    In an isolated worktree, a new session per step.

  4. Checks after every write

    Typecheck, lint, tests and build, before the next step.

  5. You accept

    Final acceptance is always human, enforced in code for every charter.

Honest limits

What is guarded — and what is not.

Guarded

  • Worktree isolation
  • Two-step confirm
  • Push blocked
  • Secrets stripped
  • Post-run checks
  • Read-only review
  • Human final acceptance

Not yet

  • Build mode has no per-tool approval gate.
  • The push guard is a brake, not a sandbox.
  • It runs on one Mac; sleep or a reboot stops it.
  • The shared remote repository is on hold.

We would rather say this here than discover it in production.
